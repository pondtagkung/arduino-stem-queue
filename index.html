Arduino STEM Queue

เครื่องมือส่วนตัวสำหรับเจ้าของช่อง TikTok สาย Arduino / STEM gadget ใช้จัดคิวคลิปสั้นที่เจ้าของสร้างเอง ตรวจดูและกดอนุมัติ แล้วส่งเข้าดราฟต์ในบัญชี TikTok ของเจ้าของเอง เจ้าของเป็นผู้กดโพสต์ในแอป TikTok ด้วยตนเองทุกครั้ง แอปนี้ไม่โพสต์แทนและไม่ให้บุคคลอื่นใช้งาน

นโยบายความเป็นส่วนตัว (Privacy Policy)

  • แอปใช้งานโดยเจ้าของบัญชีเพียงคนเดียว ผ่านการเข้าสู่ระบบด้วย TikTok (Login Kit) และขอสิทธิ์เฉพาะ video.upload
  • ข้อมูลที่เก็บ: access token และ refresh token ของบัญชีเจ้าของ เก็บไว้ในเครื่องของเจ้าของเท่านั้น
  • แอปไม่เก็บ ไม่ขาย และไม่แบ่งปันข้อมูลส่วนบุคคลกับบุคคลที่สาม
  • วิดีโอถูกส่งตรงไปยัง TikTok เพื่อบันทึกเป็นดราฟต์เท่านั้น
  • เจ้าของเพิกถอนสิทธิ์ได้ทุกเมื่อที่การตั้งค่า TikTok (Security and permissions → Manage app permissions) และลบไฟล์ token ในเครื่องได้
  • สอบถามเรื่องข้อมูลส่วนบุคคล: pondtagkung@gmail.com
